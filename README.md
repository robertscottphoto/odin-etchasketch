# Etch-A-Sketh

 Simple Etch-A-Sketch program that allows the user to populate a grid of a chosen size with any colour of the user's choice. 

## Features & Instructions

- User selects grid size: Any value between 1 and 100 is valid. 
- Select Colour from HTML5 colour picker
- Paint anywhere on the grid by hovering the cursor over any cell
- Erase any Cell colour by clicking. Erase entire sections by Clicking and Dragging 
- Select Erase All to erase all paint while retaining the current grid size.
